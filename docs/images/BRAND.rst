TypedUnit logo assets
====================

The selected "Dimensional type" mark frames a blue U with code brackets and
a mint plus. It connects Python type annotations with physical units. The
favicon uses pixel-aligned geometry on a light tile for contrast in browser tabs.

Assets in use
-------------

* ``logo.svg``: the single horizontal logo for the README and documentation.
* ``logo-dark.svg``: horizontal logo for dark documentation headers.
* ``icon.png``: square mark used as the documentation gallery thumbnail.
* ``../source/_static/favicon.svg``: browser icon.
* ``../source/_static/apple-touch-icon.png``: 180 pixel touch icon.
* ``LICENSE-DejaVu.txt``: font license for outlined wordmark lettering.

The SVG files are editable vector masters. Wordmark lettering is outlined,
so viewers do not need fonts installed. The SVG logo scales to any size; the PNG icon is 1024 by 1024 pixels. All exports use sRGB colors and preserve
transparency outside the artwork.

Palette and usage
-----------------

* Navy: ``#122B46``.
* Blue: ``#246BFD``.
* Mint: ``#43E0C0``.
* Soft white: ``#F7FAFF``.

Use the complete logo where the name needs to be readable and the square icon
for compact navigation. Below 32 pixels, use the favicon artwork. Preserve
the aspect ratio and leave clear space around the mark. Avoid adding shadows,
gradients, or color filters.

The README and documentation both use ``logo.svg`` directly.
